AI Student Performance Predictor

The AI Student Performance Predictor is a machine learning project that estimates a student's exam marks based on daily study hours, attendance percentage, and previous exam marks.

Features

- Accepts student details as input.
- Uses a machine learning model to predict estimated marks.
- Provides a simple and user-friendly web interface.
- Displays predicted marks out of 100.

Technologies Used

- Python
- Flask
- Scikit-learn
- HTML and CSS

Purpose

The purpose of this project is to demonstrate how artificial intelligence and machine learning can be used to estimate student academic performance.

Note: The predictions are estimates based on sample training data and are not guaranteed to be accurate.
